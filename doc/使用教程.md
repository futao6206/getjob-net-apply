# 使用教程

和 README 同一套顺序，这里把每一步写细。截图以后再补。

## 1. 装脚本管理器

Chrome、Edge 安装 Tampermonkey。Firefox 也可以用 Tampermonkey。Violentmonkey 能用，正文以 Tampermonkey 为准。

## 2. 允许用户脚本

新版 Chrome、Edge 需要两处都打开，否则脚本能装上，页面上却没有「网申填写」按钮：

1. 打开扩展管理，打开开发者模式。
2. 点进 Tampermonkey 的详情，打开「允许用户脚本」。

## 3. 安装本脚本

Greasy Fork 能放下完整脚本时，打开脚本页，点「安装此脚本」。

脚本带上 pdf.js 之后如果超过 Greasy Fork 的体积限制，Greasy Fork 页只留说明。这时打开下面的 GitHub Raw，Tampermonkey 会弹出安装页：

https://raw.githubusercontent.com/futao6206/getjob-net-apply/main/dist/getjob-net-apply.user.js

## 4. 保存资料

点开右下角「网申填写」。

可以逐项手填，也可以选一份本机的文字版 PDF。PDF 只在这台电脑上抽文字，不上传。超过 5 MB、超过 5 页，或者去掉空白后不足 20 个字（扫描件、图片 PDF），都不会拆字段，改成手填。

资料只有一段教育、一段工作。表上的第二段会留空。

证件号可以手填，也可以从「身份证」「证件号」后面抽。它只存在这台电脑的脚本管理器里，不上传。桌面端没有这一格，也不替你填证件号。

改完要点「保存」。没保存的修改，这次不会填进报名表。

出生日期空着时，输入框里的 `2004-01-01` 只是占位。你没改过它，报名表的出生日期会留空。

## 5. 在报名页填写

用已经登录的浏览器打开公司报名页，点「按简历填写」。

下面这些域名只是比较常见的例子。页面像报名表就会试填，不限于这几家。

| 后缀 | 例子 |
|------|------|
| `zhiye.com` | 北森，如 `vivo.zhiye.com` |
| `hotjob.cn` | 大易 |
| `mokahr.com`、`moka.com` | Moka |
| `iguopin.com` | 国聘 |
| `job.chinatelecom.com.cn` | 中国电信招聘 |

不填写 BOSS直聘、智联、猎聘、前程无忧的职位页和聊天页。

表单在 iframe 里不会填。已经写过字的格子不会覆盖。脚本不点提交、下一步、保存、新增经历。

## 6. 自己提交

看一遍已填、待核对、留空，再自己点报名站的提交。

## 没反应时

按这个顺序查：

1. 管理器是否启用。
2. 扩展详情里是否打开了「允许用户脚本」，扩展管理里是否打开了开发者模式。
3. 这页是否被认成报名表。认不出时，面板会写「这页看不出是报名表，没有填写。」
4. 表单是否在 iframe 里。在里面就不会填。
5. 资料是否点过保存。

对不上的字段留空，是预期。扫描件没有识别，改手填。

## 官网

网申填写免费，不扣积分。下载桌面端后，在「投递设置」页最底部打开。

不用安装油猴时，直接打开：

https://getjob.help/?src=net-apply&via=readme

自行套壳不在支持范围内。
