# 使用教程

和 README 同一套顺序，这里把每一步写细。截图以后再补。

所有资料保存在这台电脑上。

## 1. 装脚本管理器

Chrome、Edge 安装 Tampermonkey。Firefox 也可以用 Tampermonkey。Violentmonkey 能用，正文以 Tampermonkey 为准。

## 2. 允许用户脚本

新版 Chrome、Edge 需要两处都打开，否则脚本能装上，页面上却没有「网申填写」按钮：

1. 打开扩展管理，打开开发者模式。
2. 点进 Tampermonkey 的详情，打开「允许用户脚本」。

## 3. 安装本脚本

打开下面的地址，Tampermonkey 会弹出安装页：

https://raw.githubusercontent.com/futao6206/getjob-net-apply/main/dist/getjob-net-apply.user.js

## 4. 填写资料

点开右下角「网申填写」。

可以逐项手填，也可以选一份本机的文字版 PDF。超过 5 MB、超过 5 页，或者去掉空白后不足 20 个字（扫描件、图片 PDF），都不会拆字段，改成手填。

资料只有一段教育、一段工作。表上的第二段会留空。

改完会自动保存，不用再点保存。停手大约半秒后写入这台电脑的脚本管理器。

出生日期空着时，输入框里的 `2004-01-01` 只是占位。你没改过它，报名表的出生日期会留空。

## 5. 在报名页填写

用已经登录的浏览器打开公司报名页，点「自动填写当前页面」。这个按钮只填你正在看的这一页，不会跳去别的页面，也不代点提交。

填完后列出已填、待核对、没填上。点一项，页面滚到对应的框。有原文的可以复制，资料里空着的可以去补。面板顶部可以按住往上拖，把显示区域拉高。

不少公司的校招、秋招页挂在北森或大易上。下面这些域名比较常见。页面有姓名、手机、学校、学历、经历这类格子，就会试填。

| 后缀 | 例子 |
|------|------|
| `zhiye.com` | 北森网申，如 `vivo.zhiye.com` |
| `hotjob.cn` | 大易网申、用友大易 |
| `mokahr.com`、`moka.com` | Moka 网申、摩卡招聘 |
| `iguopin.com` | 国聘网申 |
| `job.chinatelecom.com.cn` | 中国电信招聘 |

表单在 iframe 里不会填。已经写过字的格子不会覆盖。脚本不点提交、下一步、保存、新增经历。

## 6. 自己提交

看一遍已填、待核对、留空，再自己点报名站的提交。

## 没反应时

按这个顺序查：

1. 管理器是否启用。
2. 扩展详情里是否打开了「允许用户脚本」，扩展管理里是否打开了开发者模式。
3. 这页是否被认成报名表。认不出时，面板会写「这页看不出是报名表，没有填写。」
4. 表单是否在 iframe 里。在里面就不会填。
5. 面板里是否已经有资料。修改会自动保存。

对不上的字段留空，是预期。扫描件没有识别，改手填。

## 官网

不用安装油猴，也不用配置环境。打开 GetJob 官网即可直接体验：

https://getjob.help/?src=net-apply&via=readme

网申填写免费，不扣积分。

## 桌面端

下载 GetJob 桌面端后，在「投递设置」页最底部打开。网申填写免费，不扣积分。
